# P3.5b 渲染器定点回填（复刻）

- 日期：2026-07-26（**修订**：撤销此前的 chocolate-doom 逐帧 oracle 方案，回归"复刻不是照抄"——见 roadmap §2）
- 分支：`feat/p3.5-fixed-point`（P3.5a 已落地）
- 上游：`docs/superpowers/specs/2026-07-25-roadmap-realignment-design.md`（§2 复刻声明、§4.3、§5）

## 1. 目标与范围

把 **doomcpp 自己已有的 float 渲染数学**回填为 16.16 定点；删 `bamToRendererRad` 桥；加 `finetangent`/`tantoangle` 表；顺带修本次会话发现的渲染算法偏差（上墙条件反转、plane band 公式）。

**关键约束（复刻不是照抄）**：
- 定点化是改 doomcpp **自己**的代码（P2b/P3a/P3b 写的 float 公式），**不**回去逐行翻译 vanilla `r_segs.c`。
- 可读 vanilla 源码**理解原理**（如修下墙时读 `r_segs.c:589`），但改动与验证都在 doomcpp 侧。
- **不**装 chocolate-doom、**不**做逐帧/逐像素 oracle 比对。
- 采用 16.16 定点是复刻 DOOM 的数值表示设计，非追求 bit-exact。

**不在范围**：坑底 HOM（已由 `85fdc32` 修复）；精灵/敌人/音频/存档（P4+）。

## 2. 改动组件

| 组件 | 改动 |
|---|---|
| `core/m_tables.{h,cpp}` | 新增 `finetangent[FINEANGLES+1]`、`tantoangle[2049]`（仅渲染用），`R_InitTables()` 一并生成；float 仅存于表生成处 |
| `render/r_bsp.cpp` | doomcpp 自己的 float→定点：相机基向量、seg 投影与列高、透视 U/V、距离阴影查表；`Cam` 字段改 `fixed_t`/`angle_t` |
| `render/r_plane.cpp` | `yslope`/`distscale` → 定点表；`R_DrawSpan` 跨度映射定点化 |
| `render/r_data.cpp` | 距离阴影表定点化（查表对齐） |
| `main.cpp` | 删 `bamToRendererRad`；`R_RenderView` 传 `angle_t`；`--dumpframe` 角度参数走 BAM |

（无 `tools/framediff/`——不搭 oracle 骨架。）

## 3. 步骤（doomcpp 自身测量驱动）

1. **基线**：洋红清屏 gap 扫描量化当前 float 渲染器的未覆盖区域（已知：坑底各角度 0–84、玩家起点 1671），落 `dbg/` 记录，作为"定点化不得回归"的基线。
2. **加表**：`finetangent`/`tantoangle` + 单测（表值与数学定义吻合）。
3. **r_bsp 定点化**：相机基向量、投影、列高、U/V 改 `FixedMul`/`FixedDiv`。
4. **r_plane 定点化**：`yslope`/`distscale` 表 + `R_DrawSpan` 内循环。
5. **删桥**：`main.cpp` 删 `bamToRendererRad`，`R_RenderView` 吃 `angle_t`。
6. **回归闸门**：洋红 gap 扫描 ≈ 基线（证明定点化只换表示、行为未变）+ 70/70 测试。若 gap 显著变大 → bisect 哪个定点化步骤引入。
7. **修偏差**：上墙条件 + plane band 公式（同步改，避免单独改回归），靠理解 DOOM visplane 几何 + 自身 gap 扫描验证 gap 下降。
8. **用户实机**：`doomcpp.exe` 玩着看，视觉无回归、贴图分界线消失。

## 4. 待修偏差清单（步骤 7）

- **上墙（toptexture）条件反转**：`r_bsp.cpp` 现为 `cH_b > cH_f`，正确应为后天花板**低**于前时画（vanilla `r_segs.c:570` 的 `worldhigh < worldtop`）。须与 plane band 同步改（单独改已验证会回归：pit 65→472、起点 1671→4528）。
- **plane band 公式**：高于视点的地板 / 低于视点的天花板，visplane 带算错（越过地平线覆盖下方）。
- **markCeil/markFloor 方向化**：现为 `>`/`<`，应为"高度不同"（`!=`）。

## 5. 验收（复刻自洽）

- 核心路径无 `float`/`double` 残留（仅表生成与边界 I/O 例外）；`git grep "bamToRendererRad"` 无结果。
- 既有测试 70/70 全绿。
- 洋红 gap 扫描：坑底各角度 ≤ 基线；玩家起点 gap 因上墙/plane band 修复而**显著下降**（从 1671 趋近于 0）。
- 用户实机视觉无回归；贴图"分界线"（sector 边界未覆盖像素）消失。
- 合并整个 P3.5（a+b）→ main，tag `v0.9`。

## 6. 风险与回退

- **定点化暴露隐藏 bug**：步骤 6 回归闸门若 gap > 基线即中招；`git` bisect 定位，单独修，不与 §4 算法修复混。
- **上墙/plane band 修复需理解 visplane 几何**：可读 vanilla `r_segs.c`/`r_plane.c`（已在 `dbg/`）理解原理，但实现是 doomcpp 自己的代码、靠 gap 扫描 + 实机验证。
- **`tantoangle`/`finetangent` 表尺寸/索引**：采用 vanilla `tables.h` 的常量设计（`FINEANGLES=8192`、`SLOPERANGE=2048`）避免越界——这是复刻其设计，非照抄代码。
