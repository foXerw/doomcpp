# P3.5a — Fixed-Point Foundation + Collision Backfill — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish the vanilla fixed-point foundation (`angle_t`, trig tables, `node_t`→fixed) and convert the **collision** subsystem (`p_map`/`p_maputl`) from float to 16.16 fixed-point + vanilla `finesine`/`finecosine`, with no behavior regression vs P3d.

**Architecture:** This is the first half of P3.5 (the spec's P3.5 milestone is split because the shared types `node_t`, `R_PointOnSide`, `angle_t`, and the trig tables couple collision to the renderer; splitting creates an awkward cast-ridden tree). P3.5a lands the foundation + collision; the renderer (`r_bsp`/`r_plane`) keeps its current float math and is adapted only enough to compile against the new fixed `node_t`. A small `bamToRendererRad` bridge at the `R_RenderView` call keeps the float renderer facing the same direction as P3d. P3.5b (separate plan) will convert the renderer to fixed and delete the bridge.

**Tech Stack:** C++17, MSVC (/W4, no /WX — clean but warnings non-fatal), CMake, doctest.

## Global Constraints

- **Fidelity:** algorithm + numerical dual-fidelity (16.16 fixed-point). Vanilla function semantics preserved; function names preserved.
- **`fixed_t = std::int32_t`**, `FRACUNIT = 1<<16`, `FRACBITS = 16` (already in `doomtype.h`).
- **`angle_t = std::uint32_t`** (BAM — binary angle measurement, 0..2³² = full circle, 0 = +X/East, increasing CCW toward +Y/North). `ANG45=0x20000000`, `ANG90=0x40000000`, `ANG180=0x80000000`, `ANG270=0xC0000000`.
- **Trig tables:** `FINEANGLES = 8192`, `ANGLETOFINESHIFT = 19`, `FINEMASK = 8191`. `finesine[5*FINEANGLES/4]`, `finecosine = finesine + FINEANGLES/4`. Tables are filled once by `R_InitTables()` using `std::sin` (float is allowed ONLY at table-generation time — this is how vanilla's `tables.c` was originally produced; the per-frame math is fixed-point).
- **Framebuffer convention:** RGBA8888 = `(R<<24)|(G<<16)|(B<<8)|A`; opaque black = `0x000000FF`.
- **No visual/behavior regression:** after P3.5a, the game must look and play like P3d (verified by `--dumpframe` at the E1M1 player start matching the v0.8 dump). Fixed-point rounding differences of ±1 lsb are acceptable.
- **Build:** `"$CMAKE" --build build --config Release`; tests via `--target doomcpp_tests` then `--target RUN_TESTS` (see [[doomcpp-build-and-toolchain]]).
- **Commits:** Conventional Commits, one logical unit per commit. Branch `feat/p3.5-fixed-point` (already created from `main` @ `43c853e`).

**Coordinate-literal helper for tests:** every test file touched by this plan uses `F(x) = (x) << 16` (defined in its anon namespace) to write map-unit literals as `fixed_t`. Existing tests already write vertex coords as `270 << 16`; `F()` just makes the collision coordinate args readable.

```cpp
// Binary angle measurement (r_main.c). angle_t = uint32; 0 = +X (East),
// increasing counterclockwise toward +Y (North); full circle = 2^32.
using angle_t = std::uint32_t;

inline constexpr angle_t ANG45  = 0x20000000u;
inline constexpr angle_t ANG90  = 0x40000000u;
inline constexpr angle_t ANG180 = 0x80000000u;
inline constexpr angle_t ANG270 = 0xC0000000u;

// Fine-angle trig table constants (tables.h).
inline constexpr int FINEANGLES       = 8192;
inline constexpr int FINEMASK         = FINEANGLES - 1;
inline constexpr int ANGLETOFINESHIFT = 19;        // 2^32 >> 19 == FINEANGLES

// Convert a degree quantity (DOOM THINGS angle: 0=East, 90=North) to BAM.
// 64-bit intermediate avoids truncation; exact for multiples of 45 deg.
inline angle_t degreesToBam(int deg) {
    return static_cast<angle_t>(
        (static_cast<std::uint64_t>(static_cast<unsigned>(deg)) * 0x100000000ULL) / 360ULL);
}
```

```cpp
// finesine covers a full period plus one extra quarter so that finecosine
```

- [ ] **Step 5: Implement the source** — create `src/core/m_tables.cpp`:

```cpp
#include "m_tables.h"
#include <cmath>

fixed_t  finesine[5 * FINEANGLES / 4];
fixed_t* const finecosine = finesine + FINEANGLES / 4;

void R_InitTables() {
    constexpr double twoPi = 6.283185307179586;
    const int n = 5 * FINEANGLES / 4;
    for (int i = 0; i < n; ++i) {
        // Fold into [0, FINEANGLES) so the trailing quarter period stays correct.
        double a = (i % FINEANGLES) * (twoPi / FINEANGLES);
        finesine[i] = static_cast<fixed_t>(std::sin(a) * FRACUNIT);
    }
    // finecosine aliases finesine; nothing else to fill.
}
```

```cpp
#include "p_maputl.h"
#include "core/m_fixed.h"
#include <algorithm>

// Faithful to r_main.c::R_PointOnSide: node direction is taken in map units
// (>> FRACBITS) before the FixedMul to avoid overflow, exactly as vanilla.
int R_PointOnSide(fixed_t x, fixed_t y, const node_t& n) {
    fixed_t dx = x - n.x;
    fixed_t dy = y - n.y;
    fixed_t left  = FixedMul(n.dy >> FRACBITS, dx);
    fixed_t right = FixedMul(n.dx >> FRACBITS, dy);
    return (right < left) ? 0 : 1;
}

int R_PointInSubsector(const MapData& m, fixed_t x, fixed_t y) {
    if (m.nodes.empty()) return 0;
    uint32_t nodenum = static_cast<uint32_t>(m.nodes.size() - 1);
    while (!(nodenum & NF_SUBSECTOR)) {
        const node_t& n = m.nodes[nodenum];
        nodenum = n.children[R_PointOnSide(x, y, n)];
    }
    return static_cast<int>(nodenum & ~NF_SUBSECTOR);
}

int sectorOf(const MapData& m, int subsectorIdx) {
    if (subsectorIdx < 0 || subsectorIdx >= static_cast<int>(m.subsectors.size())) return -1;
    const subsector_t& ss = m.subsectors[subsectorIdx];
    for (int i = 0; i < ss.segcount; ++i) {
        int segi = ss.firstseg + i;
        if (segi >= 0 && segi < static_cast<int>(m.segs.size())) return m.segs[segi].frontsector;
    }
    return -1;
}

// Cross-product sign test on all four bbox corners; -1 = straddle (collision
// candidate). FixedMul preserves sign; int64 intermediate avoids overflow.
int P_BoxOnLineSide(const BBox& bb, fixed_t x1, fixed_t y1, fixed_t x2, fixed_t y2) {
    fixed_t dx = x2 - x1, dy = y2 - y1;
    auto side = [&](fixed_t px, fixed_t py) -> int {
        fixed_t cross = FixedMul(dy, (px - x1)) - FixedMul(dx, (py - y1));
        // NOTE: vanilla form is dx*(py-y1)-dy*(px-x1); we keep the pre-existing
        // equivalent sign convention so the straddle result is unchanged.
        return (cross < 0) ? 1 : 0;
    };
    int s = side(bb.left, bb.bottom);
    if (s != side(bb.right, bb.bottom)) return -1;
    if (s != side(bb.left, bb.top))     return -1;
    if (s != side(bb.right, bb.top))    return -1;
    return s;
}

Opening P_LineOpening(const MapData& m, const line_t& L) {
    Opening o;
    if (L.sidenum[0] < 0 || L.sidenum[0] >= static_cast<int>(m.sides.size())) return o;
    int frontSec = m.sides[L.sidenum[0]].sector;
    if (frontSec < 0 || frontSec >= static_cast<int>(m.sectors.size())) return o;
    if (L.sidenum[1] < 0 || L.sidenum[1] >= static_cast<int>(m.sides.size())) return o;  // one-sided
    int backSec = m.sides[L.sidenum[1]].sector;
    if (backSec < 0 || backSec >= static_cast<int>(m.sectors.size())) return o;
    fixed_t fH_f = static_cast<fixed_t>(m.sectors[frontSec].floorheight)   << FRACBITS;
    fixed_t cH_f = static_cast<fixed_t>(m.sectors[frontSec].ceilingheight) << FRACBITS;
    fixed_t fH_b = static_cast<fixed_t>(m.sectors[backSec].floorheight)    << FRACBITS;
    fixed_t cH_b = static_cast<fixed_t>(m.sectors[backSec].ceilingheight)  << FRACBITS;
    o.top      = std::min(cH_f, cH_b);
    o.bottom   = std::max(fH_f, fH_b);
    o.lowfloor = std::min(fH_f, fH_b);
    o.range    = o.top - o.bottom;
    return o;
}

std::vector<int> blockLinesInCell(const Blockmap& bm, int cx, int cy) {
    std::vector<int> out;
    if (cx < 0 || cy < 0 || cx >= bm.width || cy >= bm.height) return out;
    int offset = bm.lump[4 + cy * bm.width + cx];
    if (offset < 0 || offset >= static_cast<int>(bm.lump.size())) return out;
    for (int i = offset; i < static_cast<int>(bm.lump.size()); ++i) {
        std::int16_t v = bm.lump[i];
        if (v == -1) break;
        out.push_back(v);
    }
    return out;
}
```

```cpp
#include "p_map.h"
#include "core/m_fixed.h"
#include "core/m_tables.h"
#include <algorithm>

// Vanilla m_fixed.c::P_AproxDistance (sqrt-free): |dx|+|dy| - min/2.
static fixed_t P_AproxDistance(fixed_t dx, fixed_t dy) {
    dx = std::abs(dx); dy = std::abs(dy);
    if (dx < dy) return dx + dy - (dx >> 1);
    return dx + dy - (dy >> 1);
}

PosCheck P_CheckPosition(const MapData& m, const Blockmap& bm, fixed_t x, fixed_t y) {
    PosCheck pc;
    BBox bb{ x - PLAYERRADIUS, x + PLAYERRADIUS, y - PLAYERRADIUS, y + PLAYERRADIUS };

    int sec = sectorOf(m, R_PointInSubsector(m, x, y));
    if (sec < 0) { pc.ok = false; return pc; }
    pc.floorz   = static_cast<fixed_t>(m.sectors[sec].floorheight)   << FRACBITS;
    pc.ceilingz = static_cast<fixed_t>(m.sectors[sec].ceilingheight) << FRACBITS;
    pc.dropoffz = pc.floorz;

    int xl = (bb.left   - (bm.orgx << FRACBITS)) >> MAPBLOCKSHIFT;
    int xh = (bb.right  - (bm.orgx << FRACBITS)) >> MAPBLOCKSHIFT;
    int yl = (bb.bottom - (bm.orgy << FRACBITS)) >> MAPBLOCKSHIFT;
    int yh = (bb.top    - (bm.orgy << FRACBITS)) >> MAPBLOCKSHIFT;

    static int validgen = 0;   // per-call dedup (vanilla validcount)
    ++validgen;
    for (int cy = yl; cy <= yh; ++cy)
        for (int cx = xl; cx <= xh; ++cx)
            for (int li : blockLinesInCell(bm, cx, cy)) {
                if (li < 0 || li >= static_cast<int>(m.lines.size())) continue;
                const line_t& L = m.lines[li];
                if (L.validcount == validgen) continue;
                L.validcount = validgen;
                if (L.v1 < 0 || L.v1 >= (int)m.vertices.size()) continue;
                if (L.v2 < 0 || L.v2 >= (int)m.vertices.size()) continue;
                fixed_t x1 = m.vertices[L.v1].x, y1 = m.vertices[L.v1].y;
                fixed_t x2 = m.vertices[L.v2].x, y2 = m.vertices[L.v2].y;
                fixed_t lminx = std::min(x1, x2), lmaxx = std::max(x1, x2);
                fixed_t lminy = std::min(y1, y2), lmaxy = std::max(y1, y2);
                if (bb.right <= lminx || bb.left >= lmaxx ||
                    bb.top   <= lminy || bb.bottom >= lmaxy) continue;        // bbox early-out
                if (P_BoxOnLineSide(bb, x1, y1, x2, y2) != -1) continue;      // not straddling
                if (L.sidenum[1] < 0) { pc.ok = false; return pc; }           // one-sided wall
                if (L.flags & ML_BLOCKING) { pc.ok = false; return pc; }      // explicit block
                Opening op = P_LineOpening(m, L);
                if (op.top      < pc.ceilingz) pc.ceilingz = op.top;
                if (op.bottom   > pc.floorz)   pc.floorz   = op.bottom;
                if (op.lowfloor < pc.dropoffz) pc.dropoffz = op.lowfloor;
            }
    return pc;
}

bool P_TryMove(const MapData& m, const Blockmap& bm, Player& p, fixed_t nx, fixed_t ny) {
    PosCheck pc = P_CheckPosition(m, bm, nx, ny);
    if (!pc.ok) return false;
    if (pc.ceilingz - pc.floorz < PLAYERHEIGHT) return false;   // doesn't fit vertically
    if (pc.ceilingz - p.floorz  < PLAYERHEIGHT) return false;   // not enough headroom
    if (pc.floorz   - p.floorz  > STEP_LIMIT)   return false;   // step up too high
    // MT_PLAYER carries MF_DROPOFF -> exempt from dropoff gate (vanilla). dropoffz
    // is still tracked for monster AI in P6.
    p.x = nx; p.y = ny;
    p.floorz = pc.floorz;
    p.ceilingz = pc.ceilingz;
    return true;
}

bool P_TrySlide(const MapData& m, const Blockmap& bm, Player& p, fixed_t dx, fixed_t dy) {
    if (P_TryMove(m, bm, p, p.x + dx, p.y + dy)) return true;
    if (dx != 0 && P_TryMove(m, bm, p, p.x + dx, p.y)) return true;
    if (dy != 0 && P_TryMove(m, bm, p, p.x, p.y + dy)) return true;
    return false;
}

void P_CalcHeight(const MapData& m, Player& p) {
    if (p.sector < 0 || p.sector >= static_cast<int>(m.sectors.size())) return;
    // Eye-height tracks p.floorz (bbox opening floor = vanilla tmfloorz). P3d fix preserved.
    fixed_t target = p.floorz + VIEWHEIGHT;
    p.viewz += (target - p.viewz) >> 3;                 // ~vanilla deltaviewheight >> 3
    fixed_t cap = (static_cast<fixed_t>(m.sectors[p.sector].ceilingheight) << FRACBITS) - (4 << FRACBITS);
    if (p.viewz > cap) p.viewz = cap;
}

void P_MovePlayer(const MapData& m, const Blockmap& bm, Player& p,
                  fixed_t forward, fixed_t strafe, angle_t turn) {
    p.angle += turn;   // uint32 modular wraparound
    int fi = (p.angle >> ANGLETOFINESHIFT) & FINEMASK;
    fixed_t fc = finecosine[fi];   // forward = (cos, sin) = vanilla
    fixed_t fs = finesine[fi];
    // forwardVec = (fc, fs); rightVec = (fs, -fc). Strafe sign matches P2d net direction.
    fixed_t dx = FixedMul(forward, fc) + FixedMul(strafe, fs);
    fixed_t dy = FixedMul(forward, fs) - FixedMul(strafe, fc);
    fixed_t mag = P_AproxDistance(dx, dy);
    if (mag > MAXMOVE) {
        fixed_t scale = FixedDiv(MAXMOVE, mag);
        dx = FixedMul(dx, scale);
        dy = FixedMul(dy, scale);
    }
    P_TrySlide(m, bm, p, dx, dy);
    int ss = R_PointInSubsector(m, p.x, p.y);
    p.subsector = ss;
    p.sector = sectorOf(m, ss);
    P_CalcHeight(m, p);
}
```
