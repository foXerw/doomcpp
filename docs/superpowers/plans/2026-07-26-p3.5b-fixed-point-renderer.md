# P3.5b 实现计划：渲染器定点回填（复刻路子）

> **For agentic workers:** 用 superpowers:executing-plans 逐 task 实现。步骤用 `- [ ]` 跟踪。定点化是连贯重构，建议 inline 执行（一个上下文连续改）。

**Goal:** 把 doomcpp **自己**的 float 渲染数学回填为 16.16 定点，删 `bamToRendererRad` 桥，加 `finetangent`/`tantoangle` 表，修上墙/plane-band 偏差；靠 doomcpp 自身数值自洽（洋红 gap 扫描）+ 用户实机验收。**不引入 chocolate-doom / 不逐行翻译 vanilla。**

**上游 spec:** `docs/superpowers/specs/2026-07-26-p3.5b-fixed-point-renderer-design.md`（修订版）。

## Global Constraints
- 分支 `feat/p3.5-fixed-point`；构建/测试命令见 `memory:doomcpp-build-and-toolchain`（CMake 全路径、代理 7890）。
- 帧格式 RGBA8888 = `(R<<24)|(G<<16)|(B<<8)|A`；分辨率 320×200；`--dumpframe <wad> <bmp> [angleDeg] [px py]`。
- 复刻边界：可读 `dbg/vanilla_r_*.c`（gitignored）理解**原理**；不逐行翻译、不装 oracle。
- 每步保持既有测试 70/70 全绿（除表生成处，渲染核心逐步消除 `float`/`double`）。
- 定点等价规则：`a*b`（其一为 scale/系数）→ `FixedMul(a,b)`；`a/b` → `FixedDiv(a,b)`；`std::sin/cos` → `finesine/finecosine`（已存在）；常量浮点 → `FRACUNIT` 量纲的 `fixed_t`。

### Task 2: m_tables 加 finetangent / tantoangle + 单测

**Files:** `src/core/m_tables.{h,cpp}`、`tests/test_m_tables.cpp`。

- [ ] `m_tables.h` 声明 `extern fixed_t finetangent[FINEANGLES+1];` 与 `extern angle_t tantoangle[SLOPERANGE+1];`（`SLOPERANGE=2048`，等常量加到 `doomtype.h`）。
- [ ] `m_tables.cpp::R_InitTables` 生成两表（float 仅在此处）：`finetangent[i] = tan(i * 2π/FINEANGLES / 4) * FRACUNIT`（参考 vanilla `tables.c` 的定义， Doom `ANGLETOFINESHIFT` 索引）；`tantoangle[i]` 反查（slope→angle）。
- [ ] `test_m_tables.cpp` 加测试：表值与 `std::tan`/反查数学定义吻合（采样若干点 ±2 lsb）；索引边界不越界。
- [ ] 跑测试 70→N 全绿；commit。
