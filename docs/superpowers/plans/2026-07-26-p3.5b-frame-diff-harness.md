# P3.5b 阶段 1+2 实现计划：Chocolate-Doom 逐帧比对骨架 + 基线测量

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐 task 实现。步骤用 `- [ ]` 复选框跟踪。

**Goal:** 建立 chocolate-doom 逐帧比对骨架，锁定 E1M1 标杆机位，测出当前 float 渲染器相对 vanilla 的基线偏差（数字），为 P3.5b 阶段 3（定点回填）与阶段 4（修偏差）提供测量地基。

**Architecture:** chocolate-doom 作为 oracle，用确定性 demo 回放 + F1 截图在指定 tic 落 PNG；doomcpp 用 `--dumpframe` 出同机位 BMP；Python 脚本算结构差 + 亮度差直方图。本计划只搭骨架 + 测基线，不改渲染器代码。

**Tech Stack:** chocolate-doom（Windows build）、Python 3 + Pillow（diff 脚本）、PowerShell（辅助）、既有 CMake/vcpkg 工具链。

**上游 spec:** `docs/superpowers/specs/2026-07-26-p3.5b-fixed-point-renderer-design.md`（§3 阶段 1-2、§5 骨架、§6 容差）。

- 工具链：CMake `C:\Users\User\cmake-4.4.0-windows-x86_64\bin\cmake.exe`；vcpkg `C:/Users/User/vcpkg/...`；构建命令见 `memory:doomcpp-build-and-toolchain`。

- 帧格式：RGBA8888 = `(R<<24)|(G<<16)|(B<<8)|A`，不透明黑 = `0x000000FF`。doomcpp `--dumpframe <wad> <bmp> [angleDeg] [px py]`。
- 渲染分辨率：320×200（两引擎一致）。
- 既有测试必须始终 70/70 全绿（本计划不改渲染代码，不应触动测试）。
- `dbg/` 已 gitignore；骨架产物（demo、参考截图、diff 输出）放 `tools/framediff/` 与 `dbg/diff/`。

- [ ] **Step 2: 写 diff.py**

Create `tools/framediff/diff.py`:
```python
#!/usr/bin/env python3
"""Pixel-diff two frames (chocolate-doom vs doomcpp) at 320x200.

Usage: diff.py <a.png> <b.png> [--out diff.png] [--thresh 12] [--struct 2]
Prints: struct-diff pixels, brightness histogram, PASS/FAIL vs tolerance.
"""
import argparse, json, sys
from PIL import Image

def load(p):
    im = Image.open(p).convert("RGB")
    if im.size != (320, 200):
        im = im.resize((320, 200))
    return im

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("a"); ap.add_argument("b")
    ap.add_argument("--out"); ap.add_argument("--thresh", type=int, default=12)
    ap.add_argument("--struct", type=int, default=2)
    args = ap.parse_args()
    a, b = load(args.a), load(args.b)
    pa, pb = a.load(), b.load()
    bright_diff = [0]*16        # buckets of |d|
    struct = 0
    diff_img = Image.new("RGB", (320,200))
    dp = diff_img.load()
    for y in range(200):
        for x in range(320):
            ra,ga,ba = pa[x,y]; rb,gb,bb = pb[x,y]
            d = abs(ra-rb)+abs(ga-gb)+abs(ba-bb)//3
            dp[x,y] = (abs(ra-rb), abs(ga-gb), abs(ba-bb))
            bright_diff[min(d//16, 15)] += 1
    total = 320*200
    within = sum(bright_diff[:args.thresh//16+1]) if args.thresh < 256 else total
    pct = within/total*100
    print(f"struct-buckets(by |dbrightness|): {bright_diff}")
    print(f"within thresh({args.thresh}): {within}/{total} = {pct:.2f}%")
    print("PASS" if pct > 99.0 else "FAIL")
    if args.out:
        diff_img.save(args.out)
        with open(args.out+".json","w") as f:
            json.dump({"within_pct":pct,"buckets":bright_diff}, f)

if __name__ == "__main__":
    main()
```
