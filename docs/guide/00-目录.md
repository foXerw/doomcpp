# 从零实现 DOOM：一本引擎复刻指南

> 一本讲"怎么自己写出来"的书，不是讲"原版源码长什么样"的书。
> 全书以算法原理和设计取舍为主线，用伪码和图示表达；示例代码只在你需要看清细节时出现。
> 阅读它不需要先读过 id Software 的源码——事实上，**刻意不读**也是一种方法论，第 17 章会讲为什么。

## 这本书解决什么问题

"复刻一款老游戏引擎"看起来是个翻译工作：源码是公开的，格式是文档化的，照抄就行。
真正动手之后你会发现难点完全不在这里。难点在于：

- **每一个"看起来显然"的决定都有代价。** 渲染用浮点还是定点？物件表手抄还是生成？
  遮挡用每列深度还是每像素深度？这些决定在纸面上等价，在真机上会互相打架。
- **正确性没有免费的判据。** 没有参考引擎时，"这一帧画对了"怎么证明？
  第 16 章给出一套可自动化的答案：把"不应该发生的事"写成能跑的机器检查。
- **文档化的知识会骗你。** 网上流传的 special 编号表、"原版就是这样算的"的说法，
  都可能和你手上的关卡数据矛盾。第 11 章演示如何用地图自己反证语义。

所以这本书的骨架不是"模块清单"，而是**一条实现顺序 + 每一步的判据**。

## 全书统一的写法约定

为了让 17 章读起来像一本书而不是 17 份笔记，所有章节遵守同一套约定：

1. **先讲问题，再讲算法，最后讲取舍。** 每章开头是"不做这件事会怎样"，结尾是"这样做放弃了什么"。
2. **伪码优先。** 只有当语言细节本身是知识点（定点溢出、迭代器失效、二进制布局）时才给真码。
   伪码用类 C 语法，类型名写语义而不是语言类型：`fixed32`、`angle_t(BAM)`、`mapUnits`。
3. **坐标系与单位统一**（这是老引擎最容易写错的地方，全书一次讲清）：
   - 地图单位：1 unit = 玩家半径 16 的那个单位；1 格纹理 = 1 unit；玩家直径 32、高 56、眼高 41。
   - 角度：BAM（Binary Angle Measurement），整圈 = 2³²，`ANG90 = 0x4000_0000`。
   - 屏幕：320×200，其中 320×168 是 3D 视图，底部 32 行是状态条；水平视场 90°，焦距 = 半宽。
   - 坐标：+X 东，+Y 北，`angle=0` 朝东，角度增加为逆时针。
4. **术语表**（首次出现时给中文，之后统一用中文，代码标识符保留英文）：

   | 英文 | 中文 | 含义 |
   |---|---|---|
   | linedef | 线定义 | 地图上的一条线段，携带 flags/special/tag 与两个 sidedef |
   | sidedef | 面定义 | 线的一侧：贴图名、偏移、所属 sector |
   | seg | 段 | BSP 切分后的线片段，属于某个 subsector 的边界 |
   | subsector | 子扇区 | BSP 叶子，凸区域，属于一个 sector |
   | sector | 扇区 | 一块同高地板、同高天花板、同灯光的区域 |
   | visplane | 可视平面 | 一帧中同一高度/同贴图/同灯光的平面集合 |
   | blockmap | 区块图 | 把地图按 128×128 分格、记录每格内的线与物件 |
   | mobj | 地图物件 | 会思考的东西：玩家、怪物、抛射物、道具、装饰 |
   | thinker | 思考者 | 每 tic 被调用一次的对象回调 |
   | tic | 逻辑帧 | 1/35 秒；游戏逻辑的基本时间单位 |
   | opening | 开口 | 一条两侧线"能通过"的垂直区间 [max(floor), min(ceil)] |
   | pegging | 对齐方式 | 贴图在墙面上是按顶、按底还是按世界高度固定对齐 |

5. **"忠实"的定义在书中只说一次**（第 01 章）：复刻的是**设计**——数据结构、算法流程、
   数值表示、手感；不是逐字节一致的输出，也不是把原版 C 翻译成 C++。
   凡是"原版这里到底怎么算的"无法从手上的数据判定时，本书的规则是：
   **选一个自洽且可验证的行为，并在注释里写明这是本地标定，不声称与原版逐值一致。**

## 一个提醒

这本书里的每一章，都对应一次真实的返工。第 07 章的"按 opening 收边"、
第 08 章的"每像素遮挡"、第 09 章的"脚必须跟着支撑面"、第 11 章的"用地图反证语义"，
都不是先想清楚再写的，是先写错了、被自己造的体检工具抓出来、才改对的。
所以第 16 章（验证方法论）不是附录，它是这本书真正的承重墙。
